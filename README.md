# EDA Test Patterns

Exploration of event-driven architecture testing patterns.

## Run demo (simple)

1. Install dependencies

```bash
npm install
```

2. Run the in-memory Service Bus demo

```bash
npm run demo
```

3. Optional: compile TypeScript

```bash
npm run build
```
